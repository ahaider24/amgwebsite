Results

Receipts, not case studies.

Case studies are stories an agency tells about itself. A receipt is a number with a date on it. This page only holds the second kind, and every engagement we run gets a monthly ledger built the same way.

Rule 01

Everything is dated. A number without a date is an ad.

Rule 02

Numbers a client told us are labeled client-reported. Numbers we measured are labeled measured. Never blended.

Rule 03

A baseline is a before-number, not a win. We publish the delta or we publish nothing.
