# Rebuilding

`build.py` creates both avatar directions, the GBP files, generic card PDF and their proofs. `build-moo.py -o ../REPORT.md` creates both MOO directions, the recommended alias PDF, all individual 300-DPI proofs, the comparison sheet and the report. Run that relative command from this source directory, or pass an absolute report path. They need Pillow, NumPy, ReportLab, pypdf, Node with Sharp, and Poppler. Paths to Sharp and the macOS Generic CMYK profile are near the top of `build.py`; update them for another machine. The current environment's bundled Python is `/Users/amir/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3`.

The checked-in outline JSON files make rebuilding independent of installed fonts. `font-outlines.c` extracts their ASCII outlines from the bundled genuine Google Fonts WOFF2 files using FreeType. Compile it against a FreeType build with WOFF2 support. In this environment the Pillow-bundled FreeType supports WOFF2; the Homebrew one does not. Invoke the executable as `font-outlines FONT.woff2 WEIGHT`, redirecting stdout to the corresponding JSON file. Geist is 700; Archivo is 400 and 600. Do not use a fallback face.

The avatar and GBP SVGs contain actual glyph paths, with no font dependencies. Italic uses a 14-degree shear of the real Geist glyphs because the site's CSS requests italic but loads upright Geist only. Body information uses Archivo. The source hero file is read from the repository root and never modified.

The generic PDF uses 252 x 144pt trim, 3mm bleed and an 18pt outside margin for crop marks. All lettering stays vector. The hero image on the reverse is CMYK at 300dpi. `drawPath` uses nonzero winding so overlapping font contours do not create knockout holes. PDF TrimBox, BleedBox and CMYK OutputIntent are set explicitly.

The MOO edition uses 263.52 x 155.52pt pages, a 252 x 144pt centred TrimBox, and no marks. Both PDF pages stay landscape. Its back composition is rotated inside that box for portrait reading. It places the supplied `avatars/spark-ink-1024.png` at 474 effective DPI, with the approved positioning above and a zero-ink 2.0 x 0.719 inch writing band below. The paper-front alternative uses the brand paper tint; the ink alternative uses the brand ink conversion. `moo-luxe-verification.json` records current checks. `moo-luxe-report.md` supplies the report written to `-o`. No other asset builder is executed by importing the shared drawing functions.

`verification.json` records contrast calculations, the farthest GBP artwork pixel from its centre, CMYK colour conversions, and the output profile checksum. The review contact sheets and existing-favicon audit are one-time QA composites, not regenerated by the main builder.
